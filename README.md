# Amnezia Observer

Лёгкая веб-панель для собственного сервера AmneziaWG.
**v3 by [malevnick](https://github.com/malevnick)**.
Независимый проект, не официальный продукт Amnezia.
<img width="1903" height="914" alt="image" src="https://github.com/user-attachments/assets/25b9cc73-115f-472e-9d67-e2cf4b584b5d" />

## Возможности

- Состояние VPS: CPU, доступная память, диск, сеть.
- Клиенты, приблизительная активность, имена внутри панели.
- Ручная блокировка и разблокировка.
- Месячные лимиты объёма трафика: загрузка + отправка, автоматическая блокировка.
- В новом месяце снимается ограничение по объёму, но сохраняется ручной запрет.
- Сохранение статистики в SQLite.
- QR из существующего vpn:// ключа или клиентского .conf.
- HTTPS по IP и порту, без домена и SSH-туннеля.

Python, Flask, Waitress, SQLite, nginx. Без Node.js, PostgreSQL и сборки фронтенда.
При проверке на небольшом Debian VPS три службы занимали около 43 МиБ RAM;
фактический расход зависит от нагрузки.

## Требования

- Debian 12, root и systemd; другие ОС пока не проверены.
- **Уже установленная и работающая AmneziaWG**: Docker-контейнер `amnezia-awg2`,
  интерфейс `awg0`, конфигурация `/opt/amnezia/awg/awg0.conf`.
- Python 3, доступ к Debian apt и PyPI.
- Публичный IPv4, свободный TCP-порт (по умолчанию 8443).

Панель не устанавливает сам VPN. Сначала настройте его в приложении Amnezia.
Установщик предназначен для новой установки панели и откажется перезаписывать существующую.

## Установка с нуля

На VPS войдите как root:

```bash
apt-get update
apt-get install -y git
git clone https://github.com/malevnick/amnezia-observer.git
cd amnezia-observer
bash install.sh
```

Внешний IPv4 сервера определяется автоматически. Придумайте пароль панели минимум из 14 символов.
Пароль вводится дважды без отображения. Логин: **admin**. Готового пароля нет.
Если адрес нельзя определить автоматически или нужен другой порт, можно указать их вручную:

```bash
PANEL_IP=203.0.113.10 PANEL_PORT=8443 bash install.sh
```

`203.0.113.10` - пример, замените его своим адресом.
Откройте `https://ВАШ_IP:8443/amnadmin/`.
Сначала определяется публичный адрес сетевого интерфейса. За NAT используется
HTTPS-запрос к api4.ipify.org; рабочие ключи и пароли туда не передаются.

Установщик создаёт самоподписанный сертификат. Браузер предупредит о доверии:
проверьте адрес и SHA-256 отпечаток, напечатанный установщиком, и добавьте исключение.
Соединение зашифровано. Если нужен общедоверенный сертификат, его настройка остаётся
за администратором.

При включённом firewall разрешите входящий TCP 8443 на VPS и у хостинг-провайдера.
Установщик firewall не меняет. Внутренний порт 5055 наружу не открывайте.
Существующие VPN/DNS не перезапускаются, их конфиги не переписываются.

## Клиенты и лимиты

«Настроить» меняет имя в панели, не в приложении Amnezia.
Лимит указывается в ГиБ (1024³ байт); 0 или пустое поле отключает ограничение.
Считается сумма входящего и исходящего трафика. После исчерпания лимита увеличьте
его или задайте 0 для досрочного возврата доступа. Ручной запрет снимайте отдельно.

Учёт начинается с первого наблюдения, а не с начала использования VPN.
Месяц по умолчанию определяется по Europe/Moscow. Для другого часового пояса задайте
`MONTH_TIMEZONE` в `/etc/amnezia-observer/broker.env` и перезапустите службы панели.
Лучше выбрать пояс до начала учёта.

Опрос выполняется через 3 секунды после окончания предыдущего. Возможен перерасход.
Трафик между измерением и сбросом VPN-счётчиков может потеряться; некоторые сбросы
неразличимы. Прирост на границе месяца относится к месяцу следующего измерения.
Это учёт по наблюдениям, не точный биллинг.

Блокировка удаляет peer из работающего интерфейса, сохраняя исходный конфиг.
После перезапуска Amnezia возможен короткий промежуток доступа до повторного применения.
Пока сборщик выключен, ограничения не применяются. Удалённые в Amnezia клиенты
из старых сохранённых настроек не восстанавливаются.

## QR

Для Amnezia VPN используйте существующий ключ `vpn://` из меню «Поделиться».
Для приложения AmneziaWG можно загрузить клиентский `.conf`. Это разные форматы:
[документация Amnezia](https://docs.amnezia.org/documentation/instructions/amnezia-hosting-sharing/).
Панель не создаёт новых клиентов и не восстанавливает приватные ключи.
Текст обрабатывается только в памяти вашего сервера, не сохраняется и не отправляется
в сторонние QR-сервисы. Максимум 2200 байт; для больших профилей используйте импорт файла.
QR содержит доступ к VPN, не публикуйте его.

## Управление

```bash
systemctl status amnezia-observer-broker amnezia-observer-web amnezia-observer-https
journalctl -u amnezia-observer-broker -u amnezia-observer-web -u amnezia-observer-https -n 60 --no-pager
```

Сертификат действует год. Для продления (подставьте свой IP):

```bash
python3 /opt/amnezia-observer/https_setup.py --ip 203.0.113.10 --port 8443
systemctl restart amnezia-observer-web amnezia-observer-https
```

Он перевыпускается, когда осталось менее 30 дней или изменился IP.
После перевыпуска браузеру нужно доверить новый сертификат.

### Остановить панель и снять ограничения

Следующие команды **снимают все ручные блокировки и отключают лимиты**:

```bash
systemctl stop amnezia-observer-https amnezia-observer-web amnezia-observer-broker
cd /opt/amnezia-observer
python3 recover.py --unblock-all
```

Имена и статистика сохраняются. VPN не перезапускается.

## Безопасность и хранение

Веб-процесс работает от отдельного пользователя без Docker socket.
Сборщику нужен root-доступ к Docker; его команды ограничены локальным Unix socket.
Пароль хранится как хеш, сессии подписаны случайным секретом.
Cookie: Secure, HttpOnly, SameSite=Strict; изменения требуют CSRF-токен.
После пяти неудачных входов действует общая пауза 5 минут, сбрасываемая перезапуском веб-процесса.

- `/etc/amnezia-observer/`: настройки, хеш пароля, секрет сессий, TLS-ключ.
- `/var/lib/amnezia-observer/`: ручные блокировки, SQLite с именами, лимитами, статистикой.
- `/opt/amnezia-observer/`: код и venv.

Не публикуйте эти рабочие каталоги или их резервные копии. Репозиторий содержит
только исходники, фиктивные тестовые данные и инструкции, без рабочих учётных данных.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.lock
.venv/bin/python -m unittest discover -s tests -v
DEMO=1 .venv/bin/python app.py
```

Демо: `http://127.0.0.1:5055/amnadmin/`, `admin` / `demo-preview`.
Это только локальная демонстрация с вымышленными данными; в рабочем режиме
такого пароля нет. Демо не моделирует автоматическое исчерпание лимита.

Протестированы Linux-развёртывание, HTTPS, авторизация сессии и чтение статистики.
Автотесты блокировок и лимитов используют имитацию Amnezia. Реальную блокировку
сначала проверьте на отдельном тестовом клиенте.
